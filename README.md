Topics include OOP, classes and objects, constructors, inheritance, polymorphism, pointers, functions, STL, and other core C++ concepts.

# CDAC C++ Assignment Structure

Folder naming format:

```text
1.1-ProblemName
```

* **First number** → Assignment number
* **Second number** → Problem number
* **ProblemName** → Problem/topic name

Example:

```text
1.1-Namespaces
```

→ Assignment 1, Problem 1.

Inside each problem folder, questions are named:

```text
P1/
P2/
P3/
...
```

* **P1** → Question 1
* **P2** → Question 2
* **P3** → Question 3

Example:

```text
1.1-Namespaces/
├── P1/
├── P2/
└── P3/
```

The same naming convention is followed for all assignments and problems.
